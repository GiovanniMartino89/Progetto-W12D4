# Progetto-W12D4

Progetto finale Python:  analisi vendite e rivenditori

Progetto di analisi dati in Python (pandas, NumPy, Matplotlib, Seaborn, Plotly, scikit-learn) svolto per il corso di Epicode Data Analysis.

# Scenario

Un'azienda vende prodotti di tre categorie (Outdoor, Giochi da tavolo, Giocattoli) tramite una rete di 300 rivenditori in 9 paesi europei, raggruppati in tre aree di vendita (Sud, Centro e Nord Europa). Il progetto analizza le transazioni avvenute con tre obiettivi: capire l'andamento del fatturato, prevedere i rivenditori a rischio di abbandono e raggruppare i rivenditori in segmenti omogenei.

#Task svolti

1. Python di base**: liste, tuple, set e dizionari; funzioni, cicli for e while.
2. Ispezione e pulizia dei dati;
3. Aggregazioni e serie temporali;
4. Visualizzazione: grafico a linee (Matplotlib), boxplot e heatmap (Seaborn), barre interattive (Plotly);
5. Correlazione e regressione lineare: modello semplice e multiplo del fatturato mensile, con previsione;
6. Machine learning: regressione logistica per il churn dei rivenditori e segmentazione con K-Means;
7. Debugging e refactoring.
