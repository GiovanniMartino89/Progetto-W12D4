# Progetto-W12D4

Progetto finale Python:  analisi vendite e rivenditori

Progetto di analisi dati in Python (pandas, NumPy, Matplotlib, Seaborn, Plotly, scikit-learn) svolto per il corso di Epicode DAPT0326IT.

# Scenario

Un'azienda vende prodotti di tre categorie (Outdoor, Giochi da tavolo, Giocattoli) tramite una rete di 300 rivenditori in 9 paesi europei, raggruppati in tre aree di vendita (Sud, Centro e Nord Europa). Il progetto analizza le transazioni avvenute con tre obiettivi: capire l'andamento del fatturato, prevedere i rivenditori a rischio di abbandono e raggruppare i rivenditori in segmenti omogenei.
